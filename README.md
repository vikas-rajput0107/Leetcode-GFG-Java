# Leetcode-GFG-Java

A collection of Java solutions for LeetCode and GeeksforGeeks-style problems, focused on interview preparation and problem-solving practice.

## Overview

This repository contains Java implementations organized by problem. Each folder is dedicated to a specific challenge and includes the solution source code along with a problem description/README.

## Repository Structure

```text
Leetcode-GFG-Java/
├── 0007-reverse-integer/
├── 0009-palindrome-number/
├── 0204-count-primes/
├── 1281-Subtract-Product-and-Sum/
├── 1952-Three-Divisors/
├── 2235-add-two-integers/
├── README.md
├── stats.json
└── .gitignore (if present)
```

## Included Problems

- 0007 - Reverse Integer
- 0009 - Palindrome Number
- 0204 - Count Primes
- 1281 - Subtract the Product and Sum of Digits of an Integer
- 1952 - Three Divisors
- 2235 - Add Two Integers

## How to Use

1. Open any problem folder.
2. Read the problem statement in the local README.
3. Review the Java solution implementation.
4. Compile and run it locally:

```bash
cd 0009-palindrome-number
javac Solution.java
java Solution
```
